PROJECT OVERVIEW
----------------
This project implements an AI-Based Intrusion Detection System (IDS) with a
Security Operations Center (SOC) style dashboard using Flask and Machine Learning.

The system simulates real-time cybersecurity monitoring by analyzing URLs,
generating threat scores, and displaying live security intelligence feeds.

The application also includes a simulated global traffic analytics system,
live scanning module, and user authentication system.

The system is deployed online for real-time access.

Live Deployment URL:
https://intrusion-detection-project-1.onrender.com/

SYSTEM WORKFLOW
---------------

1. User registers and logs into the system.
2. User enters a website URL for analysis.
3. System extracts features from the URL.
4. Machine Learning model predicts threat level.
5. SOC dashboard displays:
   - Threat score
   - Risk status (SAFE / MEDIUM / ATTACK)
   - Live threat feed simulation
6. Analytics module displays simulated global traffic statistics.
7. Live scan module continuously monitors selected URL.
8. All user data is stored in users.json file.
