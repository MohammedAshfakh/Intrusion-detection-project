PROJECT OVERVIEW
----------------
This project implements an Intrusion Detection System (IDS) using Machine Learning.
The system analyzes network traffic features and predicts whether the traffic
is normal or an intrusion attempt.

The web application allows users to upload network traffic data in CSV format
and uses a trained machine learning model to detect potential cyber attacks.

PROJECT DIRECTORY STRUCTURE
---------------------------

README.md
    Project description and setup instructions.

dataset/
    Contains the training dataset used to train the machine learning model.

    dataset.csv
        Training dataset with network traffic features and labels.


install-libraries/
    Contains scripts for installing required dependencies.

    install-libraries.sh
        Shell script used to install Python libraries and system packages.


model/
    Stores the trained machine learning model.

    model.pkl
        Serialized RandomForest model used for intrusion detection.


results/
    Stores prediction outputs generated by the system.

    predictions.txt
        Logs prediction results generated by the application.


src/
    Contains the core Python source code for the project.

    app.py
        Flask web application responsible for routing, prediction,
        and interaction with the trained model.

    train_model.py
        Script used to train the machine learning model using the dataset.

    generate_dataset.py
        Script used to generate synthetic training datasets for testing.


static/
    Contains static files used by the web application.

    style.css
        Stylesheet used to design the web interface.

    logo.png
        Project or university logo displayed on the website.


templates/
    Contains HTML templates used by the Flask web application.

    index.html
        Home page displaying project details and navigation.

    dashboard.html
        Dashboard displaying simulated network traffic statistics.

    upload.html
        Page used to upload network traffic CSV files for analysis.

    result.html
        Page displaying prediction results after analysis.

    about.html
        Page describing the project objectives and background.


verify-installation.sh
    Shell script used to verify whether required dependencies
    are installed correctly.


SYSTEM WORKFLOW
---------------

1. The dataset is used to train a machine learning model.
2. The trained model is stored as model.pkl.
3. The Flask application loads the trained model.
4. Users upload network traffic data through the web interface.
5. The model analyzes the data and predicts whether it is normal
   traffic or an intrusion.
6. The result is displayed on the web page.
7. The prediction is logged inside results/predictions.txt.


HOW TO RUN THE PROJECT
----------------------

Step 1: Install dependencies

sudo apt update
sudo apt install python3-flask python3-pandas python3-sklearn -y


Step 2: Train the machine learning model

python3 src/train_model.py


Step 3: Run the web application

python3 src/app.py


Step 4: Open the application in a browser

http://localhost:5000
