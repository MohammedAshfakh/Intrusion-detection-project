🛡 AI Security Operations Center

Project Overview

This is a Machine Learning based Intrusion Detection System designed to simulate real-world SOC (Security Operations Center) monitoring.

It analyzes URLs and generates real-time threat intelligence including:

  • SQL Injection Detection (Simulated)
  • XSS Attack Detection (Simulated)
  • Brute Force Pattern Monitoring
  • Live Traffic Intelligence Feed

🌐 Live Deployment

System is currently deployed at:

https://intrusion-detection-project-1.onrender.com/

⚙ Features

  • Real-time URL scanning dashboard
  • Fake SOC intelligence feed (simulated attack data)
  • Traffic analytics with geographic distribution
  • User authentication system
  • Live threat scoring engine

🎯 Purpose

This project is built for academic demonstration of how SOC systems work, combining Flask, Machine Learning, and real-time dashboards.
