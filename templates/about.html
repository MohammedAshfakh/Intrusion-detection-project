📘 About This Project

Project Title

Machine Learning Based Intrusion Detection System (SOC Web Application)

Project Description

This project is a web-based Security Operations Center (SOC) dashboard that uses Machine Learning to analyze URL or network-like input patterns and classify them as SAFE or ATTACK based on extracted features.

The system provides real-time monitoring, live threat feed simulation, analytics dashboard, and continuous scanning visualization using a Flask-based web application.
